# JMOM 免安装录制器使用说明

## 适用环境

- Windows 10/11 x64。
- 可以访问测试自动化平台和 JMOM 测试环境。
- 不需要管理员权限。
- 不需要安装 Node.js、npm、Playwright、Chrome 或 .NET Runtime。

## 下载与校验

在场景详情的“脚本与录制”页签点击“下载免安装录制器”，或从团队共享目录获取：

- `JMOM本地录制器-win-x64.zip`
- `JMOM本地录制器-win-x64.zip.sha256`

建议在 PowerShell 中校验文件：

```powershell
Get-FileHash .\JMOM本地录制器-win-x64.zip -Algorithm SHA256
Get-Content .\JMOM本地录制器-win-x64.zip.sha256
```

两处哈希值必须一致。校验后将 ZIP 解压到任意可写目录，例如 `D:\JMOM录制器`。不要直接在压缩包预览窗口中运行 EXE。

## 开始录制

1. 登录测试自动化平台。
2. 打开需要维护的测试场景。
3. 进入“脚本与录制”页签并选择测试环境。
4. 点击“开始录制”。
5. 复制平台显示的 8 位录制码，例如 `7K3P-W9QM`。
6. 双击解压目录中的 `JMOM录制器.exe`。
7. 首次使用时填写平台局域网地址，例如 `http://172.16.100.20:3050`。同事使用共享平台时不能填写 `http://localhost:3050`。
8. 输入录制码并点击“开始录制”。
9. Playwright Inspector 和目标系统浏览器打开后，按实际业务流程完成操作。
10. 操作完成后关闭 Inspector。
11. 等待录制器显示“录制脚本已上传”。平台会自动绑定脚本，可点击“刷新状态”确认。

录制码在生成后 30 分钟内有效，并且只能成功换取一次录制参数。录制器已经开始运行后，不要把同一个录制码交给其他人使用。

## 上传失败重试

如果录制已经完成但上传时网络中断，录制器会保留当前进程中的上传凭证并启用“重试上传”按钮：

1. 确认平台地址可以访问。
2. 不要关闭录制器。
3. 点击“重试上传”。
4. 上传成功后录制器会自动清理本地临时脚本。

如果录制器进程已经关闭或凭证已过期，需要回到平台重新点击“开始录制”，使用新的录制码重新录制。

## 常见问题

### 提示录制码无效或已过期

录制码可能超过 30 分钟、已被使用或输入错误。回到平台重新发起本地录制并复制新录制码。

### 提示平台地址无法访问

共享平台应填写平台电脑的局域网地址，而不是 `localhost`。可以测试：

```powershell
Test-NetConnection 平台电脑IP -Port 3050
```

### 提示运行时或浏览器文件缺失

绿色包可能没有完整解压，或文件被安全软件隔离。重新下载 ZIP、核对 SHA-256，然后解压到新目录。

### Inspector 未生成脚本

如果没有完成任何操作便关闭 Inspector，录制器会将本次任务视为取消，不会上传空脚本。回到平台重新发起录制。

### 查看日志

点击录制器中的“打开日志目录”，或打开：

```text
<录制器目录>\data\logs
```

日志不会记录上传 Token、登录密码或 Cookie。向维护人员反馈时，请提供最新日志文件、录制任务编号和错误发生时间。

## 管理员构建与发布

在项目根目录执行：

```powershell
npm ci
npm run test:recorder
npm run build:recorder
```

构建产物位于：

```text
dist\JMOM本地录制器-win-x64.zip
dist\JMOM本地录制器-win-x64.zip.sha256
```

平台默认从上述 ZIP 路径提供下载。部署时也可以通过 `JMOM_RECORDER_PACKAGE` 环境变量指定实际文件路径。
