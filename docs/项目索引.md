## 一、产品总览

### 1.1 系统定位
**AutoTest Studio** 是通用浏览器 UI 自动化测试的 **Windows 桌面工作台**。  
默认离线运行：每个项目独立目录与 SQLite；被测对象由项目内环境与用例决定，不限定行业与技术栈。

### 1.2 AutoTest Studio 技术栈

| 层级 | 技术 |
|------|------|
| 桌面壳 | Electron 40 + electron-builder（Windows x64） |
| 前端 | Vue 3 + Vue Router + Pinia + Element Plus + Vite 7 |
| 后端 / API | Node.js 22+、Express 5、SQLite（桌面内嵌） |
| 自动化 | Playwright；执行使用本机 Chrome / Edge |
| 本地录制器 | 桌面客户端内录制（Playwright codegen） |

### 1.3 桌面接入步骤

1. 安装或启动桌面客户端，创建 / 注册项目目录；可用「导出项目 / 导入项目」整包迁移。
2. 在「环境配置」填写 Base URL、账号、全局变量。
3. 录制 / 导入 Playwright 脚本，维护数据集。
4. 单条或测试计划执行，查看报告与录像；报告模板在「系统配置 → 报告模板」维护。

平台不内置业务模块模型；目录树、用例名、字段均由项目自行维护。
