# AutoTest Studio 录制编辑与本地执行体验 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在现有 AutoTest Studio上交付录制后字段/断言向导、脚本与字段双向同步、数据迁移、发布快照、草稿执行，以及桌面客户端一键唤起与绿色工具回退。

**Architecture:** 保留现有 Vue 3、Express、SQLite、Playwright 和 WinForms 录制器。后端新增聚焦的脚本分析、schema 同步、数据迁移、发布快照和桌面启动模块；`server/app.mjs` 只编排 API。前端把 `ScenarioDrawer` 拆成小组件，桌面端通过当前用户注册表注册 `autotest-recorder` 协议，同时继续接受平台地址和八位操作码。

**Tech Stack:** Node.js 22 ES Modules、Express 5、Node Test Runner、Node SQLite、Acorn、MagicString、Vue 3、Element Plus、CodeMirror 6、Playwright、.NET 10 WinForms、MSTest。

---

## 文件结构

- `server/platform/recording-analysis.mjs`：解析单测试用例 Codegen 源码，提取字段候选、已有断言并生成参数化草稿。
- `server/platform/schema-sync.mjs`：规范化 schema、计算差异、更新脚本 schema 和静态字段引用。
- `server/platform/dataset-migration.mjs`：预览字段映射并生成迁移后的行数据。
- `server/platform/scenario-releases.mjs`：创建、比较和恢复不可变发布快照。
- `server/platform/desktop-launch.mjs`：生成录制/执行协议 URL，确保 URL 不包含环境凭证或脚本数据。
- `frontend/src/components/ScriptEditor.vue`：CodeMirror 脚本编辑器。
- `frontend/src/components/RecordingReviewDialog.vue`：字段、成功条件、生成预览三步向导。
- `frontend/src/components/SchemaSyncDialog.vue`：平台字段与脚本字段的覆盖/合并交互。
- `frontend/src/components/DatasetMigrationDialog.vue`：已有数据集迁移预览和确认。
- `frontend/src/components/ScenarioReleases.vue`：发布、版本比较和恢复。
- `recorder/src/JmomRecorder.Core/RecorderLaunchRequest.cs`：解析命令行和 `autotest-recorder` URI。
- `recorder/src/JmomRecorder.Core/ProtocolRegistration.cs`：当前用户级协议注册。

```js
import assert from 'node:assert/strict';
import test from 'node:test';
import { diffSchemas, normalizeSchema, synchronizeScriptSchema } from '../../server/platform/schema-sync.mjs';

const platformSchema = normalizeSchema({
  fields: [{ key: 'customerCode', label: '客户编码', type: 'text', required: true, example: 'C001' }]
});

test('字段差异区分新增、删除、重命名和属性变化', () => {
  const scriptSchema = normalizeSchema({ columns: ['code'], required: [], example: { code: 'OLD' } });
  const diff = diffSchemas(platformSchema, scriptSchema, [{ from: 'code', to: 'customerCode' }]);
  assert.deepEqual(diff.renamed, [{ from: 'code', to: 'customerCode' }]);
  assert.equal(diff.changed[0].key, 'customerCode');
});

test('平台覆盖脚本时同步 schema 和静态 data 引用', () => {
  const source = `const testDataSchema = { columns: ['code'], required: [], example: { code: 'OLD' } };\nasync function run(data) { return data.code; }`;
  const result = synchronizeScriptSchema({ source, targetSchema: platformSchema, mappings: [{ from: 'code', to: 'customerCode' }] });
  assert.match(result.source, /customerCode/);
  assert.doesNotMatch(result.source, /data\.code/);
});

test('动态 data 引用阻止自动覆盖', () => {
  const source = `const testDataSchema = { columns: ['code'], required: [], example: { code: 'OLD' } };\nfunction run(data, key) { return data[key]; }`;
  const result = synchronizeScriptSchema({ source, targetSchema: platformSchema, mappings: [{ from: 'code', to: 'customerCode' }] });
  assert.equal(result.ok, false);
  assert.equal(result.conflicts[0].kind, 'dynamic-reference');
});
```
