# 测试平台整页菜单与框架样式优化设计

## 目标

参考用户提供的售后工单系统截图，统一优化 JMOM 自动化测试平台的侧边导航、顶部栏、页签栏和内容承载区域。改造仅影响应用框架与视觉表现，不改变现有页面切换、接口调用、测试场景管理、执行记录和设置功能。

## 现状

- 当前应用框架位于 `frontend/src/App.vue`，使用 Vue 3、Element Plus 和单一 `view` 状态切换页面。
- 当前侧边栏宽度为 224px，采用深紫色渐变背景；顶部栏只有页面标题、Runner 状态和用户入口。
- 窄屏下侧边栏直接缩为 76px，但缺少显式收起控制和完整的框架级响应式状态。
- 当前业务内容区已经使用卡片、表格、抽屉和弹窗，业务组件无需重构。

## 方案选择

采用整页高保真改造方案：调整 `App.vue` 的框架结构，并在 `frontend/src/styles.css` 中建立与参考截图一致的浅色管理后台视觉。相比只覆盖颜色，该方案能同时解决导航层级、页签表达、收起交互和内容区空间关系问题。

## 页面结构

应用登录后由以下区域组成：

1. 左侧导航栏：固定在页面左侧，展开宽度约 248px，收起宽度约 76px。
2. 顶部主栏：展示菜单按钮、面包屑、Runner 状态、当前用户和退出入口。
3. 页签栏：展示工作台入口和当前业务页签，当前页签使用紫色底边或强调色。
4. 内容区：使用浅灰蓝页面背景承载现有业务页面，保持现有业务组件结构。

## 左侧导航设计

- 品牌区使用白色背景，保留 `JMOM / 测试平台` 文案，品牌标识改为紫蓝渐变的柔和几何图形。
- 所有一级菜单增加线性图标，文字使用深灰蓝色，默认背景透明。
- 当前菜单采用紫色到蓝色的渐变背景、白色文字和轻量紫色阴影，对齐参考截图的高辨识度选中态。
- 设置菜单保留可展开子菜单。子菜单缩进展示，当前子项使用同一选中态体系，父项保持强调色提示。
- 导航底部增加“收起导航”按钮。点击后只保留品牌标识、菜单图标和展开按钮。
- 收起状态下通过原生标题提示菜单名称，避免图标含义不清。

## 顶部栏与页签栏设计

- 顶部栏高度约 58px，使用白色背景和细边框。
- 左侧展示菜单按钮和面包屑：`自动化测试 / 当前页面`。
- 右侧保留 Runner 状态，并将当前用户名和退出入口整理为紧凑操作区。
- 页签栏高度约 42px，使用白色背景。固定显示“工作台”，并显示当前业务页面页签。
- 当前页签采用紫色强调边框；页签关闭图标只作视觉表达，不引入多页缓存或关闭页面逻辑。

## 内容区设计

- 页面背景调整为偏冷的浅灰蓝色，使白色卡片边界更清晰。
- 内容区与顶部栏保持 20px 至 24px 的稳定间距。
- 保留现有场景、执行记录和设置页面的组件结构，仅统一外层高度、滚动和背景关系。
- Element Plus 主色继续使用紫色，并微调浅色阶、边框、圆角和阴影，使按钮、标签、输入框与新框架协调。

## 交互与状态

- 使用 Vue 响应式状态记录侧边栏是否收起，默认展开。
- 页面选择仍使用现有 `view` 状态，不改为路由，不改变页面组件生命周期规则。
- 点击设置子菜单后，设置分组保持展开。
- 侧边栏收起后，设置入口作为一级图标菜单显示；点击可展开侧栏并显示子菜单。
- 退出登录继续调用现有 `store.logout`，不改变认证流程。

## 响应式策略

- 宽屏桌面端完整呈现参考截图的左侧导航、顶部栏、页签栏和内容区。
- 900px 以下默认使用收起侧栏，避免主内容区过窄。
- 640px 以下隐藏非关键面包屑和页签辅助文案，顶部操作区允许换行，但保留核心页面切换能力。
- 不新增移动端抽屉导航，避免扩大本次改造范围。

## 代码范围

- `frontend/src/App.vue`：调整框架模板、菜单配置、图标、收起状态和顶部交互。
- `frontend/src/styles.css`：建立浅色侧边栏、顶部栏、页签栏、内容背景和响应式样式。
- `web-dist/`：完成验证后通过现有 Vite 构建命令更新生产前端产物。

## 验证标准

1. `npm run build:web` 成功完成且无编译错误。
2. 登录后桌面端页面与参考截图保持相同的主要布局关系：白色左栏、渐变选中菜单、双层顶部区域、浅灰蓝内容背景。
3. 测试场景、执行与报告、设置及其子菜单均可正常切换。
4. 收起与展开按钮工作正常，菜单图标和主内容区宽度同步变化。
5. 浏览器控制台无本次改造引入的 Vue 或 Element Plus 错误。
6. 在桌面宽度和一个窄屏宽度下检查遮挡、溢出、文字截断和滚动行为。

## 非目标

- 不修改业务表格字段、筛选条件、接口协议和后端服务。
- 不引入 Vue Router、多页签缓存或新的权限系统。
- 不完全复刻参考截图中的售后工单业务菜单和品牌文案。
- 不新增外部图片、字体或图标依赖。
