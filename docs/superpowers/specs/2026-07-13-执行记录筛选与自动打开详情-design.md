# 执行记录筛选与自动打开详情设计

> 日期：2026-07-13  
> 状态：已确认  
> 范围：执行记录筛选、场景执行后的详情查看交互

## 1. 背景

当前“执行与报告”页面直接展示全部执行记录，缺少按编号、场景、状态和时间定位记录的能力。测试场景创建执行任务后，页面会切换到执行记录列表，但不会直接打开刚创建任务的详情，测试人员需要再次查找并点击“查看详情”。

本次改动复用现有 `RunDialog`、`RunDetailDrawer` 和 `store.runs`，不新增页面，也不修改执行接口。

## 2. 目标

1. 执行记录支持按执行编号或场景关键词、状态、场景、开始时间范围进行组合过滤。
2. 点击场景操作栏的“执行”，完成配置并确认后，留在测试场景页并立即打开该任务的执行详情。
3. 执行详情继续按现有机制轮询步骤、截图、录像和最终结果。

## 3. 非目标

- 不增加后端分页或查询参数。
- 不修改任务创建、执行和报告生成逻辑。
- 不增加批量执行筛选或保存筛选方案。
- 不重做执行详情抽屉的视觉结构。

## 4. 执行记录筛选

### 4.1 筛选项

在执行记录表格上方增加单行筛选栏：

| 筛选项 | 控件 | 匹配规则 |
|--------|------|----------|
| 关键词 | 可清空输入框 | 同时匹配执行编号和场景名称，不区分大小写 |
| 状态 | 下拉菜单 | 全部、排队中、执行中、通过、失败、已跳过 |
| 场景 | 可清空下拉菜单 | 按 `scenarioId` 精确匹配 |
| 开始时间 | 日期范围选择器 | `startedAt` 落在所选自然日范围内，包含起止日期 |
| 重置 | 按钮 | 一次清空全部筛选条件 |

筛选在 `RunsView` 内基于 `store.runs` 计算，不改变 Pinia 中的原始记录。多个条件之间使用“并且”关系。没有匹配记录时，表格显示“暂无符合条件的执行记录”。

### 4.2 场景历史联动

从测试场景操作栏点击“历史”时：

1. 切换到“执行与报告”页面。
2. 自动把该场景写入场景筛选条件。
3. 其他筛选条件恢复默认值，避免旧条件隐藏目标记录。

`App.vue` 保存本次待应用的场景筛选，`RunsView` 通过属性接收并在变化时更新本地筛选状态。

## 5. 执行后自动打开详情

### 5.1 交互流程

1. 用户在测试场景列表点击“执行”。
2. 在 `RunDialog` 完成环境、数据和模式配置。
3. 点击“开始执行”，后端成功返回新建执行记录。
4. 关闭 `RunDialog`，保持当前页面为“测试场景”。
5. 刷新 `store.runs`，找到刚创建的记录；如果刷新结果尚未包含该记录，则使用创建接口返回的数据。
6. 立即打开 `RunDetailDrawer`。
7. 详情抽屉按现有两秒轮询机制更新，直到任务进入终态。

### 5.2 组件职责

- `RunDialog`：只负责创建任务并通过 `started` 事件返回执行记录。
- `ScenariosView`：接收 `started` 事件，刷新执行列表并打开详情抽屉。
- `RunDetailDrawer`：继续负责过程接口轮询、步骤、截图、录像和结果展示。
- `App.vue`：不再在 `started` 事件后切换到执行列表；仅在“历史”事件后切换并设置场景筛选。

### 5.3 错误处理

- 创建任务失败：保留执行配置弹窗并显示现有错误提示，不打开详情。
- 刷新执行列表失败：仍使用创建接口返回的记录打开详情，过程接口负责后续状态读取。
- 过程接口失败：沿用详情抽屉现有错误提示并停止轮询。

## 6. 测试与验收

### 6.1 自动化测试

- 筛选栏包含关键词、状态、场景、时间范围和重置入口。
- 过滤逻辑支持单条件和组合条件。
- 场景“历史”会切换页面并预选对应场景。
- `RunDialog` 创建成功后由 `ScenariosView` 打开 `RunDetailDrawer`。
- 创建成功后不会自动切换到“执行与报告”页面。

### 6.2 浏览器验收

1. 在执行记录页分别验证关键词、状态、场景和日期范围筛选及重置。
2. 验证组合筛选后表格记录均满足全部条件。
3. 从场景列表执行一个场景，确认配置弹窗关闭后当前页面不切换，详情抽屉立即出现。
4. 确认详情抽屉中的执行步骤会自动更新，并能继续查看截图、录像和 HTML 报告。
5. 检查页面无布局溢出、错误遮罩和相关控制台错误。

## 7. 实施边界

本次优先采用客户端筛选，适配当前一次性加载执行记录的架构。当执行记录规模增长到需要分页时，再统一改为后端分页与查询参数，避免本次提前扩展接口和数据库查询复杂度。
