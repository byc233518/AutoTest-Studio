# Vue 3 + Element Plus 前端替换设计

> 日期：2026-07-11
> 状态：已授权执行

## 用户目标
让测试人员以最低学习成本完成场景查找、测试数据录入、脚本录制、执行观察和证据回放。

## 信息架构
- 工作台：可执行场景、近期执行、失败数量、快捷入口。
- 场景库：应用/模块树、场景表格、就绪状态、编辑、执行、历史。
- 执行中心：运行列表、业务结果、步骤时间线、截图、录像、HTML 报告。
- 设置：应用、模块、环境、AI。

## 核心交互
- 执行采用三段式对话框：运行配置、测试数据、执行确认。
- 测试数据支持历史数据集、Excel/CSV 上传、可编辑表格三种方式。
- 表格支持增删行、规则样例、AI 样例和必填校验。
- 录制入口放在场景编辑抽屉，展示本地命令、录制状态和脚本绑定结果。
- 结果详情使用抽屉，顶部业务统计，主体步骤时间线，右侧证据预览。

## 视觉系统
- Element Plus 主色：#765ee8。
- 侧边栏保留深紫渐变，页面背景保持浅灰紫。
- 保留现有紧凑后台密度、12px 圆角和弱阴影。
- 状态颜色遵循成功绿、警告橙、失败红。

## 技术架构
- Vue 3 Composition API。
- Vite 构建，产物输出到 web-dist。
- Vue Router 管理页面。
- Pinia 管理用户、目录、运行和设置状态。
- Element Plus 提供菜单、表格、表单、弹窗、抽屉、上传、时间线和消息。
- Express 继续提供 API，并在生产模式托管 web-dist。
