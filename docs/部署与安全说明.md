# 部署与安全说明

- 本地单机默认使用 SQLite；桌面客户端数据位于用户目录 `%APPDATA%`（项目注册表与默认项目），以及用户自选的项目目录。
- 卸载安装包时会询问是否保留历史数据；默认可选保留。自行选择目录创建的测试项目不会被卸载程序删除。
- 多人长期使用建议迁移到独立数据库服务，并将上传文件和报告放入共享存储。
- 用户密码使用 scrypt 哈希保存，旧 SHA-256 记录仍兼容验证，建议用户重新设置密码完成升级。
- 环境密码和 LLM Key 仅返回脱敏值。
- 管理操作、登录、套件执行和计划触发写入审计日志。
- 生产部署应通过反向代理启用 HTTPS，并设置会话 Cookie 的 Secure 属性。
