# 部署与安全说明

## 桌面客户端（默认）

- 用 `npm.cmd run desktop:package` 生成 Windows x64 离线安装包。
- 数据位置：
  - 应用级：`%APPDATA%`（项目注册表、偏好）
  - 项目级：用户自选目录（`.autotest-studio/`、`cases/`、`data/`、`runs/`、`reports/` 等）
- 卸载时可选择是否保留 `%APPDATA%` 工作台数据；用户自建项目目录不会被删除。
- 执行与录制使用本机 Chrome / Edge，不捆绑 Chromium，不读取日常浏览器个人资料。
- 环境密码、LLM Key 仅返回脱敏值；用户密码使用 scrypt 哈希。

## 开发调试

| 方式 | 命令 | 数据 |
|------|------|------|
| 桌面 | `npm.cmd run desktop` | 当前选中的项目目录 |
| 仅 Web/API | `npm start` | 仓库 `platform-data/` |
